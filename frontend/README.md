# Phase 2: Frontend (`/frontend`)

Astro-basiertes Frontend für die Website des SprachCafés.

## Technologie Stack

- **Framework**: Astro 4
- **Styling**: Vanilla CSS / Custom CSS Variable Design System
- **Rendering**: SSG (Static Site Generation) & Hydration wo benötigt

## Lokale Entwicklung

```bash
npm install
npm run dev
```

Die Anwendung startet standardmäßig auf `http://localhost:3000`.
